# agentkit: provider-independent LLM layer

The shared layer through which every Agentic AI project calls language models. Projects depend on **one interface**, not on a vendor. Which provider runs is decided at start-up from environment variables, so adding an API key later needs **no code changes**.

```python
from agentkit import LLM, configure_logging
log = configure_logging("outputs")
llm = LLM()                                               # automatic provider and model selection
print(llm.describe())                                     # what was chosen, and why

text = llm.chat([{"role": "user", "content": "Summarise ..."}])
plan = llm.structured(messages, MyPydanticSchema)         # validated object (native JSON mode where available)
run  = llm.run_agent(messages, [get_price, search_docs])  # genuine tool-calling loop
llm.report()                                              # provenance: provider, model, live vs cached calls, tokens, cost
```

## Providers

| Provider | When it is used | Default model | Structured output | Tool calling |
|---|---|---|---|---|
| **OpenAI** (and OpenAI-compatible servers via `OPENAI_BASE_URL`, e.g. vLLM, LM Studio) | `OPENAI_API_KEY` is set | `gpt-4.1-mini` | native JSON mode + Pydantic validation | native |
| **Google Gemini** | `GOOGLE_API_KEY` or `GEMINI_API_KEY` is set | `gemini-3.5-flash-lite` | native JSON MIME type + validation | native |
| **Ollama** | no API key, and an Ollama server with a model is running | best installed (`qwen3` preferred) | native `format=json` + validation | native |
| **Hugging Face Transformers** (fully offline) | no key and no Ollama server | best Apache-2.0 Qwen3 model that fits free memory | prompt + validation + repair | native, via the model's chat template |

The local tiers (weights × 1.25 must fit in free GPU or CPU memory) are Qwen3-8B (≈ 20 GB), Qwen3-4B (≈ 10 GB), Qwen3-1.7B (≈ 5 GB) and Qwen3-0.6B. On the 8 GB, CPU-only machine used for the committed runs, the selector chose **Qwen3-1.7B**. Thinking mode is disabled for speed.

`LLM_PROVIDER` (`openai | gemini | ollama | huggingface`) forces a provider, and `LLM_MODEL` forces a model. The default API models are cost-efficient, non-reasoning models (current as of November 2026). For reasoning models (`gpt-5*`, `o*`), the temperature parameter is omitted automatically because those APIs reject it.

## Configuration

Copy [`../.env.example`](../.env.example) to `Agentic AI/.env` (shared by all projects) or to one project folder. `.env` files are found in the working directory and up to three parent directories, and the closest wins. Only the provider SDKs you use need installing: `pip install -r agentkit/requirements-providers.txt`. Offline mode needs none of them.

## Behaviour and transparency

- **Live by default.** `LLM_CACHE=off`, so every response is generated by the model in the current run.
- **Labelled caching.** With `LLM_CACHE=readwrite` (for cost saving) or `replay` (for exact reproduction offline; a cache miss raises an error), every response served from `outputs/llm_cache.json`:
  - is logged at WARNING level as `[CACHE REPLAY] … was NOT generated in this run`;
  - is tagged `"source": "cache"` in `outputs/llm_calls.jsonl`;
  - is counted separately in `llm.report()`.

  Cache keys include provider and model, so a response from one model is never served as another's.
- **Errors.**
  - Transient errors (rate limits, timeouts, 5xx) are retried with exponential backoff (3, 6, 12, 24 s), or after the delay the provider asks for ("retry in 12s"); see `LLM_MAX_RETRIES`.
  - `LLM_MIN_INTERVAL` spaces out API calls to stay under free-tier per-minute limits (e.g. `4` for a free Gemini key).
  - **Same-provider model fallback:** if a cloud model keeps failing (for example Gemini's "model is experiencing high demand"), the next model in `LLM_FALLBACK_MODELS` on the same provider is tried before the local model. This is logged as `[MODEL FALLBACK]`, and every call records the exact model that answered.
  - Authentication errors, a missing SDK, or exhausted retries trigger a **fallback to the local model** (`LLM_FALLBACK=local`, the default). It is logged as `[FALLBACK]`, recorded in the provenance report, and every later call is attributed to the provider that actually answered. Set `LLM_FALLBACK=none` to fail instead.
  - Structured outputs that fail validation are sent back to the model with the error, up to `retries` times, then raise `StructuredOutputError`.
  - In the agent loop, unknown tools, invalid arguments and tool exceptions are returned to the model as errors instead of crashing. Repeated identical tool calls are not re-executed.
- **Logging.**
  - `outputs/run.log` holds full detail.
  - `outputs/llm_calls.jsonl` has one record per call: provider, model, live or cache, latency, input and output tokens, tool-call count, estimated cost, error.
  - `outputs/llm_provenance.json` is the run summary, including the model revision hash for local models.
  - Secrets are never logged: keys appear only as "set" or "not set".
- **Reproducibility.** Temperature 0, greedy decoding locally, fixed seeds (`LLM_SEED`), and pinned model revisions recorded in the provenance file.
- **Cost.** Defaults are cheap models; per-call token counts and estimated USD cost are recorded for known models (or set `LLM_PRICE_INPUT_PER_M` / `LLM_PRICE_OUTPUT_PER_M`); local providers cost $0.

## Tests

```bash
pytest -q agentkit/tests                       # 17 offline tests, no keys or network needed
AGENTKIT_LIVE=1 pytest -q agentkit/tests       # + one live test with the local model (structured output + tool call)
```

- The **OpenAI and Ollama adapters** are exercised end to end through the real LangChain and SDK code, against local fake servers that speak each provider's HTTP protocol, including native tool calls, JSON mode and a rejected API key.
- The **Gemini adapter** builds the real client offline and is exercised with an injected chat model, because its transport goes to Google's servers.
- The **facade tests** cover provider selection order, secret redaction, model tiers, cache labelling and replay misses, retries, fallback attribution, structured-output repair, and agent-loop error handling.

The committed project runs exercised two providers live: the **offline Hugging Face** path (main notebooks) and **Google Gemini** (`runs/*_gemini.ipynb`, plus `provider_check.ipynb`). The OpenAI and Ollama paths are covered by the tests above, but were **not** run against the real services: no OpenAI key or Ollama server was available.
