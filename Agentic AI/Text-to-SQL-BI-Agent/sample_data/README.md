# Sample data

An extract of the **synthetic** pharmaceutical sales database that the notebook generates (fixed seed), for browsing without running anything: the full `products`, `regions`, `reps` and `pharmacies` tables, the first 500 `sales` rows and a sample of `targets`. The names of reps, pharmacies and products are invented. The notebook rebuilds the full database (26,665 sales) in `data/pharma_sales.db`.
